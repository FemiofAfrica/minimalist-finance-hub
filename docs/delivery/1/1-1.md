## Requirements

### Functional Requirements
1. **Data Fetching**
   - Retrieve monthly snapshots for specified time periods (3, 6, 12, 24 months)
   - Handle cases where users have less data than requested period
   - Provide fallback to current month calculations when snapshots unavailable

2. **Data Formatting**
   - Convert monthly snapshots to chart-ready data structures
   - Include proper date formatting for chart axes
   - Handle currency conversion using existing `useCurrency` context

3. **Time Period Support**
   - Support 3, 6, 12, and 24-month lookback periods
   - Exclude current incomplete month from historical analysis
   - Provide clear month labels for chart display

4. **Performance Optimization**
   - Cache data for repeated requests
   - Minimize database queries
   - Handle large datasets efficiently

### Technical Requirements
1. **Integration Points**
   - Use existing `monthlySnapshotService` functions
   - Integrate with `useCurrency` context for conversion
   - Follow existing service patterns in the codebase

2. **Data Structures**
   - Standardized interface for chart data points
   - Type-safe TypeScript interfaces
   - Consistent date handling across all functions

## Implementation Plan

### Phase 1: Core Service Structure (2 days)
1. **Create Service File**
   - Create `src/services/chartDataService.ts`
   - Define TypeScript interfaces for chart data structures
   - Set up basic service structure with error handling

2. **Data Interfaces**
   ```typescript
   interface ChartDataPoint {
     date: string;
     month: string;
     year: number;
     monthIndex: number;
   }
   
   interface BalanceChartData extends ChartDataPoint {
     balance: number;
   }
   
   interface IncomeExpenseChartData extends ChartDataPoint {
     income: number;
     expenses: number;
     net: number;
   }
   
   interface MonthlyTotalsChartData extends ChartDataPoint {
     totalIncome: number;
     totalExpenses: number;
   }
   ```

### Phase 2: Data Fetching Functions (3 days)
1. **Historical Balance Data**
   - `getBalanceTrendData(months: number): Promise<BalanceChartData[]>`
   - Fetch closing balances for each month
   - Handle currency conversion
   - Format for line chart consumption

2. **Income vs Expenses Data**
   - `getIncomeExpenseData(months: number): Promise<IncomeExpenseChartData[]>`
   - Fetch monthly income and expense totals
   - Calculate net income per month
   - Format for dual-line chart

3. **Monthly Totals Data**
   - `getMonthlyTotalsData(months: number): Promise<MonthlyTotalsChartData[]>`
   - Aggregate monthly income and expense totals
   - Format for bar chart visualization

### Phase 3: Utility Functions (1 day)
1. **Date Formatting**
   - Consistent month/year label generation
   - Chart-friendly date formatting
   - Handle timezone considerations

2. **Currency Conversion**
   - Integrate with existing currency context
   - Handle conversion errors gracefully
   - Maintain original currency for comparison

3. **Data Validation**
   - Validate monthly snapshot data
   - Handle missing months
   - Provide sensible defaults
