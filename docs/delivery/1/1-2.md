## Description

Build an interactive line chart component that displays the user's balance progression over time. This chart will show closing balances from historical monthly snapshots, with smooth curve connections and interactive tooltips. The component will be responsive and integrate with the time period filtering system.

## Requirements

### Functional Requirements
1. **Chart Visualization**
   - Display balance progression as a smooth line chart
   - Show data points for each month with hover interactions
   - Use appropriate colors (green for positive balance, red for negative)
   - Include grid lines and proper axis labeling

2. **Interactivity**
   - Tooltip showing exact balance and date on hover
   - Responsive design that works on mobile and desktop
   - Smooth animations for data changes
   - Loading and empty states

3. **Data Integration**
   - Use `chartDataService` to fetch balance data
   - Support currency conversion via `useCurrency` context
   - Handle time period changes dynamically
   - Graceful handling of missing data

4. **Visual Design**
   - Consistent with existing chart components (`ExpensesPieChart`, `RevenueChart`)
   - Professional appearance suitable for financial data
   - Clear visual indicators for positive/negative trends
   - Proper spacing and typography

### Technical Requirements
1. **React Component**
   - Functional component using React hooks
   - TypeScript for type safety
   - Proper prop interfaces and default values
   - Error boundary handling

2. **Chart Library Integration**
   - Use Recharts library (already in project)
   - Responsive container for dynamic sizing
   - Optimized rendering for performance
   - Proper cleanup on unmount

3. **State Management**
   - Local state for chart data and loading states
   - Integration with parent component for time period
   - Error state handling
   - Refresh capability for data updates
