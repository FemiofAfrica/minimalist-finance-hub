# [1-3] Create Income vs Expenses Comparison Chart

## Description

Develop a dual-line chart component that displays income and expense trends side by side over the selected time period. This visualization will help users understand the relationship between their income and expenses, identify patterns, and see the gap that contributes to their balance changes.

## Requirements

### Functional Requirements
1. **Dual-Line Visualization**
   - Display income trend as green line
   - Display expense trend as red line
   - Show both lines on the same chart for easy comparison
   - Include legend to identify each line clearly

2. **Gap Analysis**
   - Visually show the gap between income and expenses
   - Optional filled area showing net income/loss
   - Clear indication when expenses exceed income
   - Smooth line connections between data points

3. **Interactive Features**
   - Hover tooltips showing exact amounts for both income and expenses
   - Crosshair or vertical line to align data points
   - Zoom capability for detailed period analysis
   - Legend toggle to show/hide individual lines

4. **Financial Context**
   - Calculate and display net income for each month
   - Show break-even points clearly
   - Highlight periods of financial stress (expenses > income)
   - Include average lines for both income and expenses

### Technical Requirements
1. **Component Architecture**
   - Reusable React component with TypeScript
   - Proper prop interfaces for configuration
   - Integration with time period filtering
   - Error handling and loading states

2. **Data Processing**
   - Use `chartDataService.getIncomeExpenseData()`
   - Handle currency conversion seamlessly
   - Process data for optimal chart performance
   - Validate data integrity

3. **Chart Configuration**
   - Multiple line chart using Recharts
   - Responsive design for all screen sizes
   - Smooth animations and transitions
   - Professional styling consistent with app theme

   ```typescript
   interface IncomeExpenseChartProps {
     timePeriod: number;
     showNetArea?: boolean;
     showAverageLines?: boolean;
   ```
