# [1-4] Create Monthly Totals Bar Chart Component

[Back to task list](./tasks.md)

## Description

Build an interactive bar chart component that displays monthly income and expense totals side by side, allowing users to easily compare amounts across different months. This chart will provide a clear visual representation of monthly financial activity with grouped bars for income and expenses.

## Requirements

### Functional Requirements
1. **Bar Chart Visualization**
   - Grouped bar chart with income and expense bars for each month
   - Green bars for income, red bars for expenses
   - Clear month labels on X-axis
   - Currency-formatted Y-axis with appropriate scaling

2. **Interactive Features**
   - Hover tooltips showing exact amounts and percentages
   - Click interactions for future drill-down capabilities
   - Legend showing income vs expenses
   - Responsive bar sizing based on container width

3. **Data Presentation**
   - Display net income/loss indicator for each month
   - Show percentage breakdown (income vs expenses)
   - Highlight months with deficit (expenses > income)
   - Optional trend indicators between months

4. **Visual Design**
   - Professional appearance suitable for financial reporting
   - Consistent with other chart components
   - Clear visual hierarchy and spacing
   - Accessible color scheme with proper contrast

### Technical Requirements
1. **React Component Architecture**
   - Functional component with TypeScript interfaces
   - Props for customization and data handling
   - Integration with time period filtering
   - Proper state management for loading and errors

2. **Chart Implementation**
   - Use Recharts BarChart component
   - Responsive container for dynamic sizing
   - Optimized rendering performance
   - Smooth animations for data changes

3. **Data Integration**
   - Use `chartDataService.getMonthlyTotalsData()`
   - Handle currency conversion seamlessly
   - Support for different time periods
   - Graceful error handling

## Implementation Plan

### Phase 1: Component Foundation (2 days)
1. **Basic Structure Setup**
   - Create `src/components/charts/MonthlyTotalsBarChart.tsx`
   - Define TypeScript interfaces for props and data
   - Set up basic bar chart with Recharts
   - Implement loading and error states

2. **Props Interface**
   ```typescript
   interface MonthlyTotalsBarChartProps {
     timePeriod: number;
     showNetIndicators?: boolean;
     showPercentages?: boolean;
     height?: number;
     onMonthClick?: (monthData: MonthlyTotalData) => void;
     className?: string;
   }
   
   interface MonthlyTotalData {
     month: string;
     income: number;
     expenses: number;
     net: number;
     incomePercentage: number;
     expensePercentage: number;
   }
   ```
