## Requirements

1. **Month-over-Month Calculations**
   - Calculate percentage change from previous month for income, expenses, and balance
   - Calculate absolute amount differences
   - Determine trend direction (up, down, neutral)
   - Handle edge cases (previous month = 0, no previous data)

2. **Year-over-Year Calculations**
   - Compare current month to same month previous year
   - Calculate percentage and absolute changes
   - Identify seasonal patterns
   - Handle insufficient historical data gracefully

3. **Trend Analysis**
   - Determine trend strength (significant, moderate, minimal)
   - Calculate rolling averages for smoother trend detection
   - Provide trend confidence indicators

4. **Data Integration**
   - Integrate with existing monthly snapshot service
   - Use existing currency conversion system
   - Maintain consistency with current data models

## Implementation Plan

1. **Create comparative calculation service file**
   - `src/services/comparativeAnalysisService.ts`
   - Export functions for MoM and YoY calculations
   - Include proper TypeScript interfaces

2. **Implement core calculation functions**
   - `calculateMonthOverMonth(currentData, previousData)`
   - `calculateYearOverYear(currentData, yearAgoData)`
   - `calculateTrendDirection(changePercentage, threshold)`
   - `calculateTrendStrength(changePercentage)`

3. **Add utility functions**
   - `getPercentageChange(current, previous)`
   - `getAbsoluteDifference(current, previous)`
   - `formatTrendData(calculations)`

4. **Implement edge case handling**
   - Zero/null previous values
   - Missing historical data
   - Invalid date ranges
   - Currency conversion errors

5. **Add data fetching integration**
   - Integrate with existing `monthlySnapshotService`
   - Fetch required historical data efficiently
   - Cache calculations for performance
