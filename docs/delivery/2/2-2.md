## Requirements

1. **Trend Arrow Component**
   - Visual arrows indicating up, down, or neutral trends
   - Color-coded based on trend direction and context
   - Configurable size and style variants
   - Accessible with proper ARIA labels

2. **Percentage Change Component**
   - Display percentage changes with appropriate formatting
   - Color coding for positive/negative changes
   - Support for different contexts (income vs expenses)
   - Proper handling of edge cases (infinity, zero)

3. **Trend Badge Component**
   - Combined arrow and percentage in a cohesive badge
   - Multiple style variants (compact, detailed, minimal)
   - Contextual coloring based on financial metric type
   - Responsive design for different screen sizes

4. **Color System**
   - Consistent color scheme across all trend indicators
   - Context-aware colors (green for income increase, red for expense increase)
   - Accessibility compliant contrast ratios
   - Support for dark/light theme variations
