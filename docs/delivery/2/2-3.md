## Requirements

1. **Monthly Snapshot Extension**
   - Add comparative metrics to existing monthly snapshot interface
   - Include month-over-month and year-over-year calculations
   - Maintain backward compatibility with existing code
   - Ensure data availability flags are properly set

2. **Service Integration**
   - Integrate comparative analysis service with monthly snapshot service
   - Fetch required historical data efficiently
   - Handle cases where comparative data is unavailable
   - Cache comparative calculations for performance

3. **Data Structure Enhancement**
   - Extend MonthlySnapshot interface to include ComparativeInsights
   - Add optional comparative fields to avoid breaking changes
   - Include data availability metadata
   - Support both current and historical snapshot comparisons

4. **Performance Optimization**
   - Minimize additional database queries
   - Implement efficient data fetching strategies
   - Cache comparative calculations when possible
   - Ensure backward compatibility doesn't impact performance
