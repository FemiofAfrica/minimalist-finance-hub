## Requirements

### Functional Requirements

1. **Explanation Engine**
   - Create service to analyze comparative data and generate contextual explanations
   - Identify significant changes (>20% change, unusual patterns)
   - Generate human-readable explanations for trends
   - Support multiple explanation types (positive, negative, neutral)

2. **Explanation Categories**
   - **Income Changes**: Explanations for income increases/decreases
   - **Expense Changes**: Explanations for spending pattern changes  
   - **Balance Changes**: Explanations for net balance improvements/deteriorations
   - **Trend Analysis**: Explanations for multi-month trends

3. **Smart Insights**
   - Detect seasonal patterns (if data available)
   - Identify unusual spending categories
   - Suggest potential causes for significant changes
   - Provide actionable recommendations

4. **Integration Points**
   - Extend ComparisonMetrics component to show explanations
   - Add explanation tooltips/expandable sections
   - Integrate with existing trend indicators

### Technical Requirements

1. **Explanation Service**
   - Create `src/services/explanationService.ts`
   - Implement explanation generation algorithms
   - Support configurable thresholds for "significant" changes
   - Return structured explanation data

2. **UI Components**
   - Create explanation display components
   - Add interactive elements (tooltips, expandable cards)
   - Ensure explanations are contextual and helpful
   - Maintain visual consistency with existing design

3. **Data Integration**
   - Use comparative data from Task 2-3 services
   - Integrate with transaction categorization data
   - Support multiple time periods for trend analysis
