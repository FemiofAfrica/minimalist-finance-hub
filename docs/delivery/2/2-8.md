   - `validateFinancialData()` - validates financial data structures
   - `validateComparativeData()` - validates comparative insights data
   - `hasSufficientDataForComparison()` - checks data availability

   - `safeDivide()` - prevents division by zero, handles edge cases
   - `safePercentageChange()` - handles zero base values, caps extreme percentages

   - `safeCurrencyFormat()` - prevents "NGNNaN" display issues
   - `safeTrendDirection()` - safe trend calculation with fallbacks
   - `safeComparativeCalculation()` - comprehensive safe calculations
