## Requirements
1. Function
```ts
getCategoryTotals(userId: string, months: number, type?: 'income' | 'expense' | 'transfer'): Promise<CategoryAggregate[]>
```
   returns each category's sum, percentage of total, and currency.
2. Support filtering by category type (expense/income/transfer).
3. Leverage existing `dashboardService` DB access pattern.
4. Use named constants for magic numbers.
