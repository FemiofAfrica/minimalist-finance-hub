## Requirements
1. Implement `src/services/insights/recommendationEngine.ts` that exposes `generateRecommendations(analysisResult)`.
2. Rules must cover:
   • Expense reduction suggestions based on category spikes.
   • Income increase suggestions when income drop detected.
   • Cash-flow improvement strategies when expenses ≈ income.
   • Subscription review prompts for high recurring costs.
   • Savings/investment nudges on positive balance growth.
3. Pure functions; no direct I/O. Accept `InsightAnalysisResult` and return array of `Recommendation` objects (define in `types/insights.ts`).
4. Integrate into `InsightsAnalysisService` – after insight generation, call engine and append to `insights` array.
5. Unit tests covering rule logic and edge cases (`test/unit/recommendationEngine.test.ts`).
