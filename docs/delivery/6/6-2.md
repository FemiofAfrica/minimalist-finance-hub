# [6-2] Implement universal banner + safe-area offset helper

## Description
Create a reusable mechanism that ensures all top-level layouts automatically respect both the device safe-area inset (e.g. iOS notch) **and** the height of the global `SupportBanner`.  The solution must be consumable from CSS **and** React components without duplication.

## Requirements
1. Provide a CSS utility class that applies `padding-top: calc(env(safe-area-inset-top) + <banner-height>)` where `<banner-height>` is dynamic based on banner visibility.
2. Expose a React context/hook (`useTopOffset`) returning the current numeric offset so components can programmatically adjust scroll position or inline styles.
3. The context must update automatically when the banner is shown/hidden **or** when the viewport safe-area inset changes (orientation change / resize).
4. Use constants to avoid magic numbers for banner height.
5. Add documentation to the README of the context explaining usage.
