# 9-4 Add local dev proxy server

## Description
Implement a lightweight local development proxy that serves the `/api` serverless functions (`api/categorize.js`, `api/ocr.js`, etc.) so that landing-page demos work without deploying to Vercel.

## Requirements
1. Provide `dev-proxy.js` that dynamically loads handlers in `/api` and exposes them on `/api/*`.
2. Provide `groq-api-proxy.js` so that `npm run groq-proxy` no longer crashes.
3. Update `vite.config.ts` proxy to forward `/api/` to the local proxy (port 4000).
4. Ensure `npm run dev:full` runs without errors and demo calls succeed (`/api/categorize`, `/api/ocr`).
5. Add unit smoke test that the proxy returns 405 for GET `/api/categorize`.

## Implementation Plan
1. Create `dev-proxy.js` using Express.
   - `express.json()` global parser is fine (multipart ignored).
   - `POST /api/categorize` and `/api/ocr` call `import('../api/{file}')` and forward req/res.
   - Listen on port `4000` (or `process.env.API_PORT`).
2. Create minimal `groq-api-proxy.js` using `http-proxy-middleware` that forwards `/groq/*` to `https://api.groq.com`.
3. Add proxy entry in `vite.config.ts`:
   ```js
   '/api/': {
       target: 'http://localhost:4000',
       changeOrigin: true,
       secure: false
   }
   ```
4. No package.json change required (script already `proxy`: `node dev-proxy.js`).
5. Manual test: run `npm run dev:full`, issue `curl` calls -> expect 200.

## Verification
- `npm run dev:full` starts three processes without exit.
- `curl -X POST http://localhost:5173/api/categorize -H "Content-Type: application/json" -d '{"text":"Spent 5000 on groceries"}'` returns `{ success: true, category: "Groceries", ... }`.
- Uploading a small image to `POST /api/ocr` returns mock result.
- Unit smoke test passes.
