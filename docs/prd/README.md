# Kpege 2.0 Product Documentation

> **"Meet people where they are, not where you want them to be."**

This folder contains the complete Product Requirements Documentation for the reimagined Kpege—a WhatsApp-native personal finance assistant that builds financial agency through proactive nudges and frictionless transaction logging.

## The Core Pivot

**From:** A finance app users have to remember to open, log into, and actively use.

**To:** A proactive financial partner that lives in WhatsApp, nudges users at the right moments, and reduces the action required to just a simple reply.
